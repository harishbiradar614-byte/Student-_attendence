ℹ️ Project & Academic Architecture Details

Academic project specifications, biometric algorithms, and team member details.

1. Project Overview & Objective

The Smart Student Attendance System by Face Scanning automates university lecture roll calls using computer vision. Traditional manual paper registers take 10–15 minutes of lecture time and suffer from student proxy attendance. This system captures live student face frames, extracts biometric landmark vectors, and matches them strictly against registered student faces.

2. Anti-Proxy Security & Features

  • Strict Database Verification: Only faces previously enrolled via camera are verified. Any non-enrolled face triggers "❌ Face Not Saved in Database".
  • Anti-Proxy Duplicate Detection: Scanning an already-present student immediately triggers "⚠️ Face Already Scanned".
  • Sequential Periods & Breaks: Period-by-period progression with automatic faculty updates and pause during Short Break and Lunch Break.
  • Mobile-Friendly Camera Flip: Switch between front and back camera on mobile phones and tablets.
